# Test-only dependencies, on top of requirements.txt.
#
# Audit finding P2-10: `pip install -r requirements.txt` alone is not
# enough to run this project's test suite -- pytest itself was only
# ever installed as an ad hoc extra step in CI
# (`pip install -r requirements.txt pytest`), so a developer cloning
# the repo and running `pytest` after the documented install step got
# a bare "No module named pytest" with no guidance. CI happened to
# work because its install step happened to also list pytest, but
# nothing in the repository itself said so.
#
# Install with: pip install -r requirements.txt -r requirements-dev.txt
# or just run scripts/test.sh, which does both steps for you.
pytest==9.1.1
